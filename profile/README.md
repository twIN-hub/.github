# twIN Hub

> **twIN Hub** es un espacio colaborativo para el desarrollo, documentación y experimentación para **twIN**, el gemelo digital urbano de Pamplona.

Este repositorio funciona como un entorno abierto de trabajo entre desarrolladores, con el objetivo de facilitar:

- El desarrollo y testeo de **ETLs** y **pruebas de concepto (PoCs)** en un entorno seguro antes de su integración en producción.
- La contribución y mantenimiento de una **documentación viva**, que evolucione de forma paralela al desarrollo técnico.
- La práctica de **integración continua** mediante commits frecuentes, claros y alineados con principios de código limpio.
- La participación en **revisiones de código constructivas**, que promuevan la mejora continua y el intercambio de conocimiento.
- Una mayor **trazabilidad del progreso**, facilitando la identificación de bloqueos y la toma de decisiones ágiles.
- La **exploración y validación de nuevas soluciones técnicas**, fomentando la innovación desde las primeras fases del desarrollo.
